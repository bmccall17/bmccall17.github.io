two public selves

you want two public selves that tell the truth together.

  • the "portfolio" is the curated artifact: legible, calm, narrow, trustworthy.
  • the "darketype" is the living lab: messy, procedural, revealing, iterative, and intentionally unfinished. my practice arena made visible.

the promise

"i'm not hiding the sausage-making. i'm making it the proof."

most portfolios show outcomes. this shows outcomes + the engine.


the loop

  1. create a "mess entry" in 5–12 minutes.
  2. publish fast.
  3. search later.
  4. revisit and upgrade into "lesson" (optional).
  5. generate a visible timeline/graph that grows.

if the loop is smooth, the site wins. if the loop is annoying, it dies.

workshop tools

instruments built during the process. the tools are the practice.

  • ⚡ bam logo factory
    svg logo generator with chromatic aberration, glitch slices, turbulent surge, and ring distortion. built because ai iteration kept failing at logo design — so we built a tool instead.

  • ◉ per-char chromatic displacement
    interactive typography playground where every letter responds to cursor proximity with physics-based displacement and chromatic fringe. the R&D staging ground for viscous.js.

  • ⬡ agent828 prototypes
    sandbox for agent828 landing page effects — iris widget, split slider, progressive reveal, redacted document, and crosshair widget. live lab for dual-mode landing concepts.
