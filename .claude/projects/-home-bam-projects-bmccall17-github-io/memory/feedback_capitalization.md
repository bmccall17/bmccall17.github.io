darketype entries are written in all-lowercase style, but proper names (people, places, brands, game titles) must be capitalized.

**Why:** the user caught uncapitalized "miyamoto" and corrected it — proper names need caps even in the lowercase darketype voice.

**How to apply:** when writing darketype entries, keep general prose lowercase but capitalize: person names (Miyamoto, Koji Kondo), brand/company names (Nintendo, GDC), game titles (Super Mario Bros), place names (Bob-omb Battlefield). If unsure whether something is a proper noun, capitalize it.
