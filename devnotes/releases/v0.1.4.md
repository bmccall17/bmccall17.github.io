# v0.1.4 - dynamic chaos

**released:** february 13, 2026

## summary
a refactor of the weblog engine to support dynamic, client-side loading of entries. inverted the binary interaction (text first, chaos on hover) and added epoch timestamp reveals.

---

## changes
- **interaction flip:** titles now display as readable text by default and flip to binary "cypher" on hover.
- **dynamic loading:** `weblog/index.html` now fetches `entries.json` on load, allowing for instant updates without full HTML rebuilds.
- **timestamp fidelity:** build script now uses actual file creation timestamps (birthtime) instead of frontmatter dates.
- **epoch reveal:** hovering a title now swaps the date format to unix epoch timestamp.
- **watcher script:** added `scripts/watch_weblog.js` to auto-rebuild the manifest on file changes.

---

## files changed
