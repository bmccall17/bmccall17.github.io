# v0.1.9 - 🖥️ responsive matrix layout

**released:** may 29, 2026

## summary
Upgraded the main portfolio landing page from a single stream of ghost cards to a robust two-column ghost tile layout. The new architecture supports varying card sizes (`.hero-card`, `.small-card`) and seamlessly drops the "contributions" calendar matrix graph directly into the page flow as a fixed horizontal backdrop. 

Crucially, the mobile layout was bulletproofed to prevent horizontal blowout from flex overflows, and the sidebar was re-engineered to prevent overlapping sticky contexts on smaller viewports.

---

## changes

### layout & architecture
- migrated `experimental-layout.html` grid architecture to `index.html`.
- replaced the old single-column `.projects-grid` with the new `.layout-columns` grid.
- updated `loadContributions` logic to generate 156 weeks (3 years) of data squares to fully bleed the matrix background horizontally.

### css & rendering
- fixed `.ghost-card` specificity rules to correctly enforce `.hero-card` (320px) and `.small-card` (140px) vertical dimensions.
- implemented `.leak-section` `min-width: 0` constraints to prevent flex grid blowout on desktop viewports.
- wrapped `#calendar-graph` in an absolute container to prevent its 1800px width from stretching the layout viewport.

### mobile responsive fixes
- disabled `position: sticky` on `.profile-sidebar` at `<768px` viewports to prevent z-index collision and overlapping rows on mobile scrolling.
- added `flex: 1` and `min-width: 0` constraints to `.ghost-content` to prevent long text strings (especially in flex-row layouts) from triggering horizontal scrolling.
- fully verified the `@media (max-width: 768px)` override block drops the layout into a clean vertical stack.
