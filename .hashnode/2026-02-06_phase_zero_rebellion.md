# The problem
We needed a place to break things without breaking the "professional" us.

# The learning
Binary code (0 and 1) is a perfect metaphor for "planning vs acting". Phase 0 is the pause. Phase 1 is the glitch.
Also, `mkdir` is faster than `list_dir` when you know the folder doesn't exist yet.

# The mess
- Imported workflows from other projects, then immediately broke them (re-wrote them in lowercase).
- Established a "chaos" rule set that demands we ignore grammar police.
- Tried to list a directory before creating it, causing a nice red error in the logs. Perfect.
